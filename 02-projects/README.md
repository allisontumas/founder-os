# What this is

One folder per business bet — the project's *card*: business context, vision, decisions, feedback. Code lives in each bet's own repo and flows here via `SYNC-DIGEST.md`.

# The rules

- **README is mandatory; other files are created the day they first have real content** (see `templates/project-card.md` for the full set). `critical-path-weekly/` is deliberately README-only — that's what a young card looks like.
- **No card without Connections** — a bet earns a folder only after scoring ≥12 on [prioritization.md](../01-foundation/prioritization.md) and writing the Connections section in its `product-vision.md`.
- Cards own **business** to-dos; the code repo owns **build** to-dos (fed via the digest's Outbound lane). Never mix them.
- Parked ideas live in [ideas.md](ideas.md) with their rubric score and a revisit date.

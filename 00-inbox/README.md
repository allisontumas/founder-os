# What this is

The capture mouth. Anything lands here as a dated markdown file — pasted ChatGPT session digests, notes, agent drafts — and `/digest` routes it by tag (grammar in the root README). Fully-routed files get deleted (git history is the archive); anything unroutable stays for the next pass. Never let filing slow down capture.

# Template: studio card

A creative project's folder in `03-studio/`. Same gate as business bets (rubric + Connections) — dreams get scored too, they just score differently (a 5 on energy can carry a 1 on flywheel).

```
03-studio/<name>/
├── README.md          # logline + Connections + status
├── treatment.md       # the story/theory itself (or outline.md for books)
├── characters/        # one file per character: want, need, voice, arc
├── scenes/            # one file per scene/beat (chapters/ for books)
└── references.md      # per-project moodboard: visual/tonal/sound, each with a *why*
```

Worked example: `03-studio/float/`.

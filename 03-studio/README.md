# What this is

Creative work — films, books, songs, art. Studio cards follow `templates/studio-card.md`: README (logline + Connections), treatment, `characters/`, `scenes/` (or `chapters/`), and `references.md` as the per-project moodboard. Same Connections gate as business bets, scored on the same rubric — creative work isn't exempt from "why this," it just answers differently.
